Twitch Chat Commands

!discord - Get an invite link to our community discord server.
!socials - Link to my Bluesky profile.
!age - Tells you my age.
!clip - Clips last 30 seconds of stream and automatically posts it to the discord server.
!clippost - !clippost followed by a clips url to post it automatically to ⁠the discord server.
!time - My current local time.
!uptime - How long the streams been up for.
!vod - Link to the Vod Channel.
!youtube - Link to the Main Channel.
!followage - Check how long you've been following for.
!watchtime - Check how long you've been watching for.
!lurk - Let chat know you are hanging out quietly in the background.
!song - Shows the title of the song as well as the game its from.
!commands - Takes you to this very page that lists current channel commands.
